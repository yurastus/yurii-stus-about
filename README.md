# CV Website

A simple, polished personal CV website built with HTML, CSS, and JavaScript.

## Run locally

Open the folder in a browser or serve it with a local server:

```bash
cd cv-site
python3 -m http.server 8000
```

Then visit http://127.0.0.1:8000/.

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Push this folder to the repository.
3. In GitHub settings, enable GitHub Pages and choose the main branch.
